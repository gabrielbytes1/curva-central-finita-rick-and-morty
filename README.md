# A Curva Central Finita de Rick and Morty

Projeto de pesquisa desenvolvido com apoio do NotebookLM a partir de fontes abertas sobre a Curva Central Finita, Rick C-137 e Evil Morty.

## Objetivo
Investigar o que é a Curva Central Finita, sua origem, funcionamento e importância para a narrativa de *Rick and Morty*, diferenciando informações apresentadas pela série de interpretações, análises e teorias encontradas nas fontes.

## Metodologia
A pesquisa foi desenvolvida em etapas no NotebookLM: conceito geral; origem e propósito; funcionamento; Evil Morty; auditoria; importância narrativa; síntese; glossário. A auditoria foi usada para evitar que interpretações ou informações externas às fontes fossem tratadas como fatos.

## Níveis de evidência
- **Canon:** informação apresentada ou confirmada pela série, conforme a pesquisa.
- **Fortemente sustentado:** apoiado pelas fontes, mas não detalhado explicitamente pela animação.
- **Interpretação/análise:** leitura crítica dos autores das fontes.
- **Teoria/especulação:** hipótese sem confirmação suficiente.
